Teacher Dashboard

Demo: this page reads the stand-in data kept in this browser. The real version would need your teacher sign-in. The sample class is filled with four weeks of made-up practice from the real decks; any class you create starts empty, and fills up as its students sign in and practise.

Teacher sign-in

This is the password you set in the Google Sheet's Latin Site menu. You stay signed in on this computer for about a week.

New class

Each student gets a login (a Latin, Greek or Phoenician name) and a password made of two Latin words. Real names are never needed.

Sign-in slips

Print or copy these now. Passwords are shown only once and aren't stored in a readable form. If a student loses one, use Reset password on their row.

To match slips to students, write each student's name on your own copy, or type it into the private label on their row (that label stays in this browser only).

Cards the class misses most

Counted across every student: answered Again in spaced repetition, or marked Still learning in practice. These are good candidates for a review lesson.

    What the site stores

    • Stored: the class code, each login name (an invented name), the password in hashed form, and practice activity: flashcard answers, grammar pages opened, and game scores, with the time of each.
    • Not stored: real names, email addresses, birthdays or any other personal details. Students can't create accounts or type anything about themselves.
    • Your labels: if you label a login with a student's real name, the label is kept only in this browser on this computer. It never goes to the site.
    • Deleting: deleting a class removes its logins and all of their activity.
